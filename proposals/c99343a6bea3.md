## Budget-Aware Sequential Experiment Selection

**Priority:** high
**Module:** evolution
**Risk:** medium
**Paper:** Spend Less, Fit Better: Budget-Efficient Scaling Law Fitting via Active Experiment Selection

### Description
A method for intelligently selecting which experiments to run from a pool of available options, considering both cost and expected information gain. It uses uncertainty-aware allocation to maximize learning efficiency while minimizing resource expenditure.

### How to Apply
This could dramatically improve agos's ability to efficiently explore and optimize its own performance across different tasks and configurations. Rather than running exhaustive experiments on agent strategies or parameter tuning, agos could intelligently select which experiments yield the most valuable insights for its current objectives.

#### Budget-Aware Sequential Design
Intelligently selects next experiments based on cost-benefit analysis and uncertainty reduction. Uses active learning to maximize information gain per unit cost, preventing expensive experiments until sufficient information is gathered.
```python
async def select_next_experiment(self, candidate_pool, current_results, budget_remaining, target_region):
    """Select next experiment to maximize expected information gain per cost."""
    scores = []
    for candidate in candidate_pool:
        # Estimate information gain using current model uncertainty
        uncertainty = await self.estimate_uncertainty(candidate)
        cost = self.cost_function(candidate)
        # Cost-adjusted information gain
        score = uncertainty / (cost ** self.cost_penalty_exp)
        scores.append((score, candidate))
    
    # Select highest scoring experiment within budget
    scores.sort(reverse=True)
    for score, candidate in scores:
        if self.cost_function(candidate) <= budget_remaining:
            return candidate
    return None
```

#### Multi-Output Scaling Law Fitting
Handles complex parametric models with multiple outputs and Jacobian computation for gradient-based optimization. Supports multiple backends (numpy/jax/torch) with automatic differentiation for fitting complex relationships.
```python
async def fit_scaling_model(self, theta_init, X_data, y_data, backend='numpy'):
    """Fit parametric model with automatic differentiation support."""
    import numpy as np
    from scipy.optimize import minimize
    
    def objective(theta):
        pred, jac = self.model_fn(theta.reshape(1, -1), X_data, backend=backend)
        residual = pred.ravel() - y_data.ravel()
        loss = np.sum(residual ** 2) / len(residual)
        grad = (2.0 / len(residual)) * jac.reshape(-1, len(theta)).T @ residual
        return loss, grad
    
    result = minimize(objective, theta_init, method='L-BFGS-B', 
                     jac=True, options={'maxiter': 2000, 'ftol': 1e-15})
    return result.x, result.fun
```

#### Multi-Start Optimization with Parallelization
Runs multiple optimization attempts in parallel to avoid local minima, then selects the best result. Critical for robust parameter fitting in complex, non-convex optimization landscapes.
```python
async def multistart_optimization(self, objective_fn, bounds, n_starts=32, n_workers=8):
    """Run multiple optimization starts in parallel to find global optimum."""
    import asyncio
    import numpy as np
    from scipy.optimize import minimize
    
    # Generate random starting points
    starts = []
    for _ in range(n_starts):
        start = np.array([np.random.uniform(lo, hi) for lo, hi in bounds])
        starts.append(start)
    
    # Parallel optimization
    async def optimize_single(start_point):
        loop = asyncio.get_event_loop()
        result = await loop.run_in_executor(None, 
            lambda: minimize(objective_fn, start_point, method='L-BFGS-B', bounds=bounds))
        return result.x, result.fun
    
    tasks = [optimize_single(start) for start in starts]
    results = await asyncio.gather(*tasks)
    
    # Return best result
    best_params, best_score = min(results, key=lambda x: x[1])
    return best_params, best_score
```

#### Fisher Information Acquisition Function
Uses Fisher Information Matrix to quantify expected information gain from potential experiments. Provides principled uncertainty estimation for active learning by measuring how much new data points would reduce parameter uncertainty.
```python
async def compute_fisher_information_gain(self, candidate_x, current_params, current_data):
    """Compute expected Fisher information gain for a candidate experiment."""
    import numpy as np
    
    # Current Fisher Information Matrix
    pred, jac = self.model_fn(current_params, current_data)
    FIM_current = jac.T @ jac + self.prior_precision * np.eye(len(current_params))
    
    # Expected Fisher information from candidate
    pred_new, jac_new = self.model_fn(current_params, candidate_x.reshape(1, -1))
    FIM_candidate = jac_new.T @ jac_new
    
    # Information gain (log determinant difference)
    try:
        gain = 0.5 * np.log(np.linalg.det(FIM_current + FIM_candidate) / 
                           np.linalg.det(FIM_current))
    except np.linalg.LinAlgError:
        gain = 0.0
    
    return max(0.0, gain)
```

#### Checkpointed Progressive Evaluation

#### Parametric Model Registry
Organized registry system for different model types with metadata about parameter counts, bounds, and computational complexity. Enables systematic comparison and selection of appropriate models for different domains.
```python
class ModelRegistry:
    """Registry for parametric models with metadata."""
    
    def __init__(self):
        self.models = {}
        self.cost_functions = {}
        self.param_bounds = {}
    
    def register_model(self, name: str, model_fn, param_count: int, 
                      bounds: list, cost_fn=None, complexity='medium'):
        """Register a new parametric model."""
        self.models[name] = {
            'function': model_fn,
            'param_count': param_count,
            'bounds': bounds,
            'complexity': complexity,
            'cost_function': cost_fn or (lambda x: 1.0)
        }
    
    async def select_best_model(self, data_size: int, target_accuracy: float):
        """Select most appropriate model given constraints."""
        candidates = []
        for name, info in self.models.items():
            # Estimate model suitability
            complexity_penalty = {'low': 1.0, 'medium': 1.5, 'high': 2.0}[info['complexity']]
            param_penalty = info['param_count'] / (data_size + 1)  # Avoid overfitting
            score = target_accuracy / (complexity_penalty + param_penalty)
            candidates.append((score, name, info))
        
        return max(candidates, key=lambda x: x[0])
```

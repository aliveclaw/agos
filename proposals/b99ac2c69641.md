## IoT-Augmented World Modeling

**Priority:** high
**Module:** coordination
**Risk:** medium
**Paper:** IndoorR2X: Indoor Robot-to-Everything Coordination with LLM-Driven Planning

### Description
Integrates observations from multiple heterogeneous sources (mobile agents and static IoT sensors) to construct a comprehensive global semantic state. Uses LLM-driven planning to coordinate actions based on this enriched environmental understanding.

### How to Apply
agos could leverage ambient IoT sensors and triggers to build richer environmental context for multi-agent coordination. This would enhance the Knowledge System with persistent environmental state and improve coordination strategies beyond current agent-to-agent communication.

### Implementation Hint
Extend the Triggers system to ingest IoT sensor data, enhance the Knowledge System to maintain global environmental state, and modify coordination strategies to use this ambient intelligence for better task planning and resource allocation.

## Fixed-Capacity Importance-Based Recurrent State

**Priority:** high
**Module:** knowledge
**Risk:** low
**Paper:** Linear Scaling Video VLMs for Long Video Understanding

### Description
StateKV maintains cross-frame context in a fixed-size state buffer that retains the most important information while discarding less relevant details. It uses importance scoring to determine what context to preserve as new information flows through the system, enabling linear scaling instead of quadratic growth.

### How to Apply
This could dramatically improve agos's Working Memory module by implementing importance-based context retention that maintains key information while staying within capacity limits. The technique would also enhance the Memory Consolidation system by providing a principled way to compress episodic memories while preserving the most critical insights.

### Implementation Hint
Implement an importance scoring function for memory entries and context items, then maintain a fixed-size buffer that evicts lowest-importance items when capacity is reached. Adapt the recurrent state approach to preserve cross-conversation context in working memory while enabling linear scaling with conversation length.

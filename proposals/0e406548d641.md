## Query-Aware Evidence Seeking Loop

**Priority:** high
**Module:** kernel
**Risk:** high
**Paper:** VideoSeek: Long-Horizon Video Agent with Tool-Guided Seeking

### Description
A think-act-observe loop that actively seeks answer-critical evidence instead of exhaustively processing all available data. The system uses query context to guide selective observation and reduces computational overhead while maintaining or improving understanding capability.

### How to Apply
This could dramatically improve agos's efficiency when processing large datasets or complex multi-step tasks by enabling selective, goal-directed information gathering rather than brute-force processing. The technique would be especially valuable for the Intent Engine when breaking down complex plans and for agents operating under token budget constraints.

### Implementation Hint
Extend the Agent Kernel's state machine to include a 'seek' state that uses query context to selectively gather observations. Implement a toolkit of observation functions that can be called based on the current task requirements, allowing agents to efficiently navigate large information spaces while staying within token budgets.

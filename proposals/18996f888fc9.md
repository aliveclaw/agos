## Model-Generated Skill Extraction and Consumption

**Priority:** high
**Module:** knowledge
**Risk:** low
**Paper:** From Raw Experience to Skill Consumption: A Systematic Study of Model-Generated Agent Skills

### Description
A systematic approach to extract structured procedural skills from agent experiences and enable their reuse across different tasks and agents. The technique involves analyzing the full lifecycle of experience generation, skill extraction, and skill consumption to identify what makes skills transferable and useful.

### How to Apply
Agos could leverage this to automatically extract reusable skills from agent executions, building a dynamic skill library that improves performance across tasks. The meta-skill guidance approach could help agos identify which extracted procedures are most likely to transfer successfully to new contexts.

### Implementation Hint
Implement a skill extraction system that analyzes successful agent executions to identify reusable procedural patterns, store them in the knowledge system with utility metrics, and provide a skill consumption mechanism that selects and adapts relevant skills for new tasks based on the meta-skill guidance framework.

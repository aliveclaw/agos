## Reasoning-First Query Expansion

**Priority:** medium
**Module:** intent
**Risk:** medium
**Paper:** CoVR-R:Reason-Aware Composed Video Retrieval

### Description
Uses large multimodal models to infer causal and temporal consequences from user queries before executing retrieval. The system reasons about implicit after-effects and consequences that aren't directly stated in the original query.

### How to Apply
Could enhance agos's Intent Engine by expanding natural language requests into more comprehensive execution plans that account for implicit consequences and after-effects of actions. This would make the system more proactive and thorough in its planning.

### Implementation Hint
Modify the Intent Engine to include a reasoning step that uses the LLM to expand user intents by predicting likely consequences and after-effects. Cache these reasoned expansions in the Knowledge System to improve future planning accuracy.

#### Context-Aware Embedding Extraction Strategy
Uses layered embedding extraction with token importance weighting and normalization. Extracts embeddings from different model layers (last, penultimate) and applies weighted pooling based on token significance to improve semantic representation quality.
```python
class EmbeddingExtractor:
    def __init__(self, embedding_source='penultimate', pooling='weighted_mean', normalize=True):
        self.embedding_source = embedding_source
        self.pooling = pooling
        self.normalize = normalize
    
    async def extract_embeddings(self, hidden_states, token_mapping, attention_weights=None):
        """Extract contextual embeddings with importance weighting"""
        if self.embedding_source == 'penultimate' and len(hidden_states) > 1:
            embeddings = hidden_states[-2]  # Use second-to-last layer
        else:
            embeddings = hidden_states[-1]
        
        if self.pooling == 'weighted_mean' and attention_weights is not None:
            # Weight tokens by attention importance
            weights = attention_weights.mean(dim=1).squeeze()
            weighted_emb = (embeddings * weights.unsqueeze(-1)).sum(dim=1)
            pooled = weighted_emb / weights.sum()
        else:
            pooled = embeddings.mean(dim=1)
        
        if self.normalize:
            pooled = F.normalize(pooled, p=2, dim=-1)
        
        return pooled.cpu().numpy()
```

#### Multi-Stage Reasoning Pipeline
Implements a reasoning pipeline that first analyzes what changes will occur, then generates the final output based on that analysis. This two-stage approach improves reasoning quality by separating analysis from synthesis.
```python
class ReasoningPipeline:
    def __init__(self, model, reasoning_tokens=128, synthesis_temp=0.6):
        self.model = model
        self.reasoning_tokens = reasoning_tokens
        self.synthesis_temp = synthesis_temp
    
    async def multi_stage_reasoning(self, context, task_instruction):
        """Two-stage reasoning: analysis then synthesis"""
        # Stage 1: Analysis
        reasoning_prompt = f"""Analyze this task: {task_instruction}
        Context: {context}
        
        Identify in 2-3 sentences:
        1. What specific changes or actions are needed
        2. The key considerations and constraints
        
        Be concrete and focus on actionable insights."""
        
        reasoning_response = await self._generate_text(
            reasoning_prompt, max_tokens=self.reasoning_tokens, temperature=0.7
        )
        
        # Stage 2: Synthesis using reasoning
        synthesis_prompt = f"""Based on this analysis:
        {reasoning_response}
        
        Now execute the task: {task_instruction}
        Context: {context}
        
        Provide the final result incorporating the insights from your analysis."""
        
        final_response = await self._generate_text(
            synthesis_prompt, temperature=self.synthesis_temp
        )
        
        return {
            'reasoning_trace': reasoning_response,
            'final_output': final_response,
            'context': context
        }
```
**Integration steps:** 1. Integrate into Intent Engine for complex plan generation. 2. Use for multi-step agent coordination decisions. 3. Apply to memory consolidation for creating structured insights from episodic memories.

#### Self-Consistency Reasoning Validation
Generates multiple reasoning samples at higher temperature, then synthesizes the most consistent elements. This improves reliability of complex reasoning tasks by leveraging multiple perspectives and finding consensus.
```python
class SelfConsistencyReasoning:
    def __init__(self, model, num_samples=5, sample_temp=0.9, synthesis_temp=0.6):
        self.model = model
        self.num_samples = num_samples
        self.sample_temp = sample_temp
        self.synthesis_temp = synthesis_temp
    
    async def self_consistent_reasoning(self, prompt, context):
        """Generate multiple reasoning samples and synthesize consensus"""
        samples = []
        
        # Generate multiple reasoning samples
        for i in range(self.num_samples):
            sample = await self._generate_reasoning(
                prompt, context, temperature=self.sample_temp
            )
            samples.append(sample)
        
        # Synthesize consensus from samples
        synthesis_prompt = f"""Review these {len(samples)} reasoning attempts for the same problem:
        
        {self._format_samples(samples)}
        
        Identify the most consistent and well-supported elements across attempts.
        Synthesize a final answer that incorporates the strongest reasoning."""
        
        consensus = await self._generate_text(
            synthesis_prompt, temperature=self.synthesis_temp
        )
        
        return {
            'samples': samples,
            'consensus': consensus,
            'confidence': self._calculate_consistency_score(samples)
        }
    
    def _calculate_consistency_score(self, samples):
        # Simple heuristic: count overlapping key terms
        all_terms = [set(s.lower().split()) for s in samples]
        intersection = set.intersection(*all_terms) if all_terms else set()
        union = set.union(*all_terms) if all_terms else set()
        return len(intersection) / len(union) if union else 0.0
```
**Integration steps:** 1. Use in multi-agent debate coordination for consensus building. 2. Apply to critical decision points in agent workflows. 3. Integrate with knowledge system for validating important insights before storage.

#### Hierarchical Recall Evaluation System
Implements a comprehensive recall evaluation system with multiple thresholds (R@1, R@5, R@10, etc.) for measuring retrieval performance. Useful for evaluating and optimizing memory retrieval and agent selection systems.
```python
class HierarchicalRecallEvaluator:
    def __init__(self, thresholds=[1, 5, 10, 50, 1000]):
        self.thresholds = thresholds
    
    async def compute_recall_metrics(self, similarity_scores, ground_truth_indices):
        """Compute recall at multiple thresholds for retrieval evaluation"""
        ranks = np.zeros(len(ground_truth_indices), dtype=np.float32)
        
        for query_idx, (scores, gt_idx) in enumerate(zip(similarity_scores, ground_truth_indices)):
            # Sort by similarity (highest first)
            sorted_indices = np.argsort(scores)[::-1]
            matches = np.where(sorted_indices == gt_idx)[0]
            ranks[query_idx] = matches[0] if matches.size > 0 else len(scores)
        
        total = len(ranks)
        metrics = {}
        
        for threshold in self.thresholds:
            recall = 100.0 * np.count_nonzero(ranks < threshold) / total
            metrics[f'R@{threshold}'] = round(recall, 4)
        
        # Add mean of top 3 metrics
        top_3_keys = [f'R@{t}' for t in self.thresholds[:3]]
        if all(k in metrics for k in top_3_keys):
            metrics['R_mean'] = round(sum(metrics[k] for k in top_3_keys) / 3.0, 4)
        
        return {
            'metrics': metrics,
            'ranks': ranks,
            'success_rate': np.count_nonzero(ranks < max(self.thresholds)) / total
        }
```

#### Token Mapping and Filtering System
Implements intelligent token filtering using stop words and importance scoring to focus on meaningful content. Includes domain-specific stop words for video/visual content that can be adapted for other domains.
```python
class TokenProcessor:
    def __init__(self, domain='general'):
        self.stop_words = self._get_stop_words(domain)
    
    def _get_stop_words(self, domain):
        base_stops = {"the", "a", "an", "and", "or", "but", "in", "on", "at"}
        
        if domain == 'agent':
            domain_stops = {
                "agent", "system", "process", "execute", "run", "task", "action",
                "function", "method", "call", "invoke", "trigger", "handle",
                "response", "result", "output", "input", "data", "information"
            }
        elif domain == 'memory':
            domain_stops = {
                "memory", "remember", "recall", "store", "retrieve", "save",
                "information", "data", "content", "knowledge", "fact", "detail"
            }
        else:
            domain_stops = set()
        
        return base_stops | domain_stops
    
    async def filter_and_map_tokens(self, tokens, embeddings, importance_threshold=0.1):
        """Filter tokens and create importance mapping"""
        filtered_tokens = []
        filtered_embeddings = []
        token_mapping = {}
        
        for i, token in enumerate(tokens):
            cleaned = token.lower().strip('.,!?;:')
            
            # Skip stop words and short tokens
            if cleaned not in self.stop_words and len(cleaned) > 2:
                # Calculate token importance (simplified)
                importance = self._calculate_importance(token, embeddings[i] if embeddings else None)
                
                if importance > importance_threshold:
                    filtered_tokens.append(token)
                    if embeddings:
                        filtered_embeddings.append(embeddings[i])
                    token_mapping[len(filtered_tokens)-1] = {
                        'original_index': i,
                        'token': token,
                        'importance': importance
                    }
        
        return filtered_tokens, filtered_embeddings, token_mapping
    
    def _calculate_importance(self, token, embedding=None):
        # Simple importance heuristic - can be enhanced
        base_score = 1.0 / (1 + len(token) * 0.1)  # Slightly prefer longer tokens
        if embedding is not None:
            norm_score = float(np.linalg.norm(embedding))
            return base_score * norm_score
        return base_score
```

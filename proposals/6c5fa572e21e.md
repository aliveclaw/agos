## Preference Coordinated Multi-Agent Policy Optimization

**Priority:** high
**Module:** coordination
**Risk:** medium
**Paper:** Learning Coordinated Preference for Multi-Objective Multi-Agent Reinforcement Learning

### Description
PCMA learns coordinated agent-specific preferences to enable complementary trade-offs among agents in multi-objective scenarios. It formulates cooperative multi-agent problems as team-optimal games where preference diversity induces team improvement through strategic coordination rather than uniform optimization.

### How to Apply
This could significantly improve agos's Multi-Agent Coordination module by enabling agents to specialize in different objectives (speed vs accuracy, exploration vs exploitation) while maintaining team coherence. Instead of all agents using identical strategies, they could develop complementary preferences that collectively optimize the overall system performance.

### Implementation Hint
Implement a preference learning layer in the coordination module that assigns different objective weights to agents based on their roles and past performance. Use the existing team strategies (pipeline/parallel/debate) as the foundation, but add preference optimization that allows agents to specialize while maintaining team-level objectives through coordinated trade-offs.

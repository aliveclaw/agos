## Mask-Based Discrete Diffusion Architecture

**Priority:** medium
**Module:** kernel
**Risk:** high
**Paper:** Omni-Diffusion: Unified Multimodal Understanding and Generation with Masked Discrete Diffusion

### Description
A unified architecture that uses mask-based discrete diffusion models to process and generate multimodal content (text, speech, images) by capturing joint distributions over discrete tokens. Unlike autoregressive models, it can handle bidirectional dependencies and parallel generation across modalities.

### How to Apply
This could replace agos's current LLM backbone (Claude API) with a self-hosted multimodal foundation model that natively handles text, audio, and visual inputs/outputs. This would enable agos agents to directly process images, audio files, and generate multimodal responses without needing separate vision/speech APIs.

### Implementation Hint
Implement a multimodal diffusion model wrapper that can replace the current Claude API calls in the Intent Engine. Add multimodal token handling to the Agent Kernel's state machine and extend the Tool Bus with native image/audio processing capabilities using the unified diffusion backbone.

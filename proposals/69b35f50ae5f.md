## Two-Stage Perception-Decision Pipeline

**Priority:** medium
**Module:** intent
**Risk:** high
**Paper:** Fly360: Omnidirectional Obstacle Avoidance within Drone View

### Description
A system that first processes omnidirectional sensory input into robust intermediate representations (depth maps), then uses a lightweight policy network to generate action commands. The approach separates perception processing from decision-making for better modularity and performance.

### How to Apply
Agos could use this pattern to better process complex environmental information before making decisions. The Intent Engine could benefit from a perception stage that converts natural language and context into structured intermediate representations before the decision stage generates execution plans.

### Implementation Hint
Implement a preprocessing layer in the Intent Engine that converts natural language inputs and environmental context into structured intermediate representations (like semantic graphs or task templates). Then have the decision layer generate execution plans from these processed representations rather than raw inputs.

#### Spherical Convolution Memory Pooling
Uses omnidirectional spherical convolutions to aggregate spatial features from 360° panoramic views. This creates spatially-aware memory representations that preserve geometric relationships across the full visual field.
```python
class SpatialMemoryPool:
    def __init__(self, kernel_size=(3, 3), alpha=0.8, max_scale=4.0):
        self.kernel_size = kernel_size
        self.alpha = alpha
        self.max_scale = max_scale
        self.memory_grid = {}
    
    async def aggregate_spatial_memory(self, observations: torch.Tensor, locations: torch.Tensor):
        """Aggregate memories using spherical convolution for spatial coherence"""
        H, W = observations.shape[-2:]
        # Create spherical sampling grid for memory aggregation
        lat_idx, lon_idx = self._create_spherical_grid(H, W)
        
        # Apply spatial weighting based on proximity
        spatial_weights = self._compute_spatial_weights(locations)
        
        # Aggregate memories with spherical convolution
        aggregated = torch.zeros_like(observations)
        for i in range(len(observations)):
            for j in range(len(observations)):
                weight = spatial_weights[i, j]
                if weight > 0.1:  # threshold for relevance
                    aggregated[i] += weight * observations[j]
        
        return aggregated
    
    def _create_spherical_grid(self, H, W):
        # Spherical coordinate mapping for memory indexing
        phi = torch.linspace(-torch.pi/2, torch.pi/2, H)
        theta = torch.linspace(-torch.pi, torch.pi, W)
        return phi, theta
```

#### Staged Pipeline Processing
Two-stage processing pipeline (RGB → depth → control) that allows intermediate representations for better decision making. Each stage can be optimized independently while maintaining coherent end-to-end processing.
```python
class StagedPipeline:
    def __init__(self):
        self.stages = []
        self.intermediate_cache = {}
    
    async def add_stage(self, name: str, processor: callable, cache_intermediate=True):
        """Add a processing stage to the pipeline"""
        self.stages.append({
            'name': name,
            'processor': processor,
            'cache': cache_intermediate
        })
    
    async def process(self, input_data: dict, context: dict = None):
        """Process through staged pipeline with caching"""
        current_data = input_data.copy()
        
        for stage in self.stages:
            # Check cache first
            cache_key = f"{stage['name']}_{hash(str(current_data))}"
            if cache_key in self.intermediate_cache:
                current_data = self.intermediate_cache[cache_key]
                continue
            
            # Process through stage
            result = await stage['processor'](current_data, context)
            
            # Cache if enabled
            if stage['cache']:
                self.intermediate_cache[cache_key] = result
            
            current_data = result
        
        return current_data
    
    def clear_cache(self, stage_name: str = None):
        """Clear cache for specific stage or all stages"""
        if stage_name:
            keys_to_remove = [k for k in self.intermediate_cache if k.startswith(stage_name)]
            for key in keys_to_remove:
                del self.intermediate_cache[key]
        else:
            self.intermediate_cache.clear()
```
**Integration steps:** 1. Replace direct LLM calls with staged pipeline for intent parsing. 2. Add intermediate caching for common intent patterns. 3. Enable hot-swapping of processing stages for different agent capabilities.

#### Layered Learning Rate Scheduling
Different learning rates for different model layers based on their depth and role, allowing fine-grained control over adaptation. This enables efficient meta-learning by adjusting update rates for different components.
```python
class AdaptiveParameterScheduler:
    def __init__(self, base_lr=1e-3, decay_factor=0.9):
        self.base_lr = base_lr
        self.decay_factor = decay_factor
        self.parameter_groups = {}
    
    async def create_parameter_groups(self, agent_components: dict):
        """Create learning rate groups for different agent components"""
        for component_name, component in agent_components.items():
            # Assign learning rates based on component criticality
            if component_name in ['memory', 'knowledge']:
                # Lower LR for stable components
                lr = self.base_lr * 0.1
            elif component_name in ['planning', 'reasoning']:
                # Higher LR for adaptive components  
                lr = self.base_lr
            else:
                # Medium LR for other components
                lr = self.base_lr * 0.5
            
            self.parameter_groups[component_name] = {
                'lr': lr,
                'weight_decay': 1e-5 if 'memory' in component_name else 1e-4,
                'update_count': 0
            }
    
    async def update_learning_rates(self, performance_metrics: dict):
        """Adapt learning rates based on performance"""
        for component_name, group in self.parameter_groups.items():
            if component_name in performance_metrics:
                perf = performance_metrics[component_name]
                # Increase LR if performance is improving
                if perf.get('improving', False):
                    group['lr'] *= 1.1
                else:
                    group['lr'] *= self.decay_factor
                
                # Clamp learning rate
                group['lr'] = max(group['lr'], 1e-6)
                group['update_count'] += 1
    
    def get_lr_for_component(self, component_name: str) -> float:
        return self.parameter_groups.get(component_name, {}).get('lr', self.base_lr)
```

#### Angular Feature Decomposition
Decomposes complex features into angular components using spherical harmonics for better spatial understanding. This enables more structured representation learning that preserves directional relationships.
```python
class AngularFeatureDecomposer:
    def __init__(self, hidden_dim: int, max_degree: int = 3):
        self.hidden_dim = hidden_dim
        self.max_degree = max_degree
        self.degree_params = {0: 3, 1: 3, 2: 5, 3: 7}  # spherical harmonic params
        self.projectors = {}
        
    async def setup_projectors(self):
        """Setup projection layers for different angular degrees"""
        for degree, num_params in self.degree_params.items():
            self.projectors[degree] = {
                'linear': torch.nn.Linear(self.hidden_dim, num_params * self.hidden_dim),
                'activation': torch.nn.GELU(),
                'norm': torch.nn.LayerNorm(self.hidden_dim)
            }
    
    async def decompose_features(self, features: torch.Tensor, context_directions: torch.Tensor):
        """Decompose features into angular components"""
        decomposed = {}
        
        for degree in range(self.max_degree + 1):
            # Project features for this degree
            projected = self.projectors[degree]['linear'](features)
            projected = self.projectors[degree]['activation'](projected)
            
            # Reshape for angular processing
            batch_size, seq_len = features.shape[:2]
            num_params = self.degree_params[degree]
            angular_features = projected.reshape(batch_size, seq_len, num_params, self.hidden_dim)
            
            # Apply directional weighting based on context
            if context_directions is not None:
                weights = self._compute_angular_weights(context_directions, degree)
                angular_features = angular_features * weights.unsqueeze(-1)
            
            decomposed[f'degree_{degree}'] = angular_features
        
        return decomposed
    
    def _compute_angular_weights(self, directions: torch.Tensor, degree: int):
        """Compute angular weights for spherical harmonic degree"""
        # Simple angular weighting - can be enhanced with actual spherical harmonics
        theta = torch.atan2(directions[..., 1], directions[..., 0])
        phi = torch.acos(directions[..., 2].clamp(-1, 1))
        return torch.cos(degree * theta) * torch.sin(degree * phi)
```
